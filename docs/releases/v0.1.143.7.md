## 回滚目标

如新版本出现健康检查失败、工具页回归、panic/fatal、迁移错误、端口绑定失败或网关请求大面积失败，立即将 `D:\sub2api-deploy\proxy\upstreams\active.conf` 切回：

```nginx
upstream sub2api_active {
  server sub2api-blue:8080;
  keepalive 32;
}
```

然后执行：

```powershell
docker exec sub2api-proxy nginx -t
docker exec sub2api-proxy nginx -s reload
```
