## 详细更新日志

1. 扩展 NewApi 签到服务，复用各账号现有 access key 只读请求上游 `/api/token/?p=1&size=100`，并限制为 6 路并发。
2. 新增管理接口 `GET /api/v1/admin/newapi-checkin/api-keys`；接口只返回账号、Key 名称和脱敏值，不返回上游完整 API Key。
3. 脱敏格式统一为 `sk-前2位***后4位`；上游 Key 没有 `sk-` 前缀时由展示层补齐，避免页面出现无前缀的密钥文本。
4. 签到工具的平台目录新增 `API Key` 列；有 Key 时显示脱敏结果，无 Key 显示“未生成”，读取失败显示“读取失败”。
5. API Key 在页面读取 SQL 主数据后异步加载，不阻塞站点、账号、余额、签到历史和月度历史的初始展示。
6. 同步更新公共签到 HTML、管理端嵌入页面、前端测试和后端 service/handler 测试。
