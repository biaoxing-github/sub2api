## 功能与用户影响

- OpenAI Chat Completions 流读取中断现在返回稳定的断流分类；已开始写流时不会重复追加终态，Ops 记录逻辑状态码和 SLA 诊断字段。
- 池模式临时不可调度规则按账号和模型生效，已知模型只冷却对应模型；401 和基础设施账号熔断语义保持不变。
- 过期管理员订阅重新分配时会续期并重置窗口与用量，suspended 订阅不会被自动激活。
- Anthropic Responses 补齐完整终态输出，Antigravity 付费套餐类型和 Anthropic 监控文本能够正确保留与提取。
- Claude Code 模型名的 `[1m]` 后缀会在网关请求阶段归一化。
- Grok 精确命中 `invalid encrypted_content` 时会清除加密推理载荷，并使用同一账号、token 和缓存身份重试一次。
- 支付套餐有效期文案不再写死天数；自定义站点标题和 favicon 在首屏注入，运行时 favicon URL 经过过滤。
- 仓库 compose 中 Redis 持久化参数改为 Redis 8 支持的配置形式。

## 涉及模块

- `backend/internal/handler`：OpenAI 流错误响应与 Ops 诊断。
- `backend/internal/pkg/apicompat`：Anthropic Responses 终态转换。
- `backend/internal/service`：临时调度规则、模型冷却、订阅续期、Antigravity、监控文本、Claude 和 Grok 兼容。
- `backend/internal/web`、`frontend/src`、`frontend/vite.config.ts`：品牌首屏、favicon 和套餐有效期文案。
- `deploy/docker-compose.yml`：Redis 持久化参数。
