## 更新内容

- Claude Code 通过 Anthropic `/v1/messages` 进入 OpenAI 兼容转发时，如果上游返回 HTTP 400 且正文包含 `There was an issue with the format or content of your request` 与 `request id`，将其归入可切换上游的临时处理错误。
- 该判断接入既有 `shouldFailoverOpenAIUpstreamResponse` 失败切换链路，在向客户端写出响应前返回 `UpstreamFailoverError`，让外层调度继续尝试其他远端账号。
- 匹配条件保持窄口径：必须同时满足 HTTP 400、格式或内容问题固定文案、request id，避免把普通客户端 400 全部吞掉。
