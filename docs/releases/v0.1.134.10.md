## 更新内容

- OpenAI Codex CLI 模拟指纹从 `0.125.0` 更新为 npm 当前 `@openai/codex` 最新 `0.138.0`。
- `DefaultOpenAICodexUserAgent` 与账号级 Codex CLI 模拟使用同一 `codex_cli_rs/0.138.0` User-Agent，减少上游最新版客户端校验差异。
- 管理端 OpenAI Responses 与 `/responses/compact` 人工测试复用正式 `OpenAIGatewayService.buildUpstreamRequestWithBaseURL`，不再维护第二套手写 header 请求逻辑。
- 人工测试入口补齐入站 Codex 客户端身份后再走正式 builder，确保 `free5` 这类账号级模拟请求带上正常 `User-Agent`、`originator`、`OpenAI-Beta` 和 `version`。
