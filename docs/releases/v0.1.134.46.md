## 更新内容

- 修复 gptai-plus 这类 OpenAI Responses 流：上游返回 `response.completed` / `response.done` 和输出 delta，但缺少 `response.usage` 与 `data: [DONE]` 时，下游终态事件补零值 usage，并补写 `data: [DONE]`。
- 保持已有 `data: [DONE]` 的上游不重复写结束标记，避免客户端收到重复终止事件。
- 管理端调度池人工测验成功后恢复账号可调度、清理账号错误状态与 OpenAI path-health 降级状态；普通上游体检和后台体检仍只记录体检结果，不自动修复调度池状态。
- OpenAI 调度耗尽探测保留临时冷却账号作为等待候选，避免小池子冷却期被当成空池快速失败。
- 管理端账号列表 usage 摘要标题使用叶子翻译 key，避免显示根 key；补齐调度池页面 `shallowRef` 导入，恢复前端 typecheck。
