## 详细更新日志

1. 签到工具新增 `sub2api` 只读数据源，只调用 `/v1/usage?days=30` 和 `/v1/models`，不进入签到、月度同步、NewAPI Key 枚举或远端名称同步流程。
2. 新增套餐、余额、累计请求、Token、成本、到期时间和模型分组展示，并将读取结果写入既有余额缓存的 `provider_data` 字段。
3. 新增 `POST /api/v1/admin/newapi-checkin/account-display-name`，允许管理员在平台目录手工填写用户名或邮箱标识，复用既有 `display_name` 字段，不保存账号密码。
4. sub2 站点不提供签到和月度同步动作；相关入口由服务端规则和页面状态共同禁用。
5. 同步更新 SQL 迁移、repository/service/handler/server 路由、公共签到 HTML、管理端嵌入页面、前端类型和测试。
6. 生产数据库新增站点 `sub-vcnovb`，协议为 `sub2api`，后台签到关闭；账号 `primary` 的 Key 仅以 `sk-90***84cd` 脱敏复核。

## 回滚

将 `D:\sub2api-deploy\proxy\upstreams\active.conf` 的 upstream 改回 `sub2api-green:8080`，执行 `docker exec sub2api-proxy nginx -t`，通过后执行 `docker exec sub2api-proxy nginx -s reload`。部署配置备份为 `D:\sub2api-deploy\.env.bak-v0.1.155.1-20260715-120136`，upstream 备份为 `D:\sub2api-deploy\proxy\upstreams\active.conf.bak-v0.1.155.1-20260715-120136`。
