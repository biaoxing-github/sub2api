## 功能与用户影响

- NewAPI 手动同步会逐个读取 token 的完整 API Key，并通过现有 `match_keys` 字段保存到数据库。
- 平台目录普通加载、完整 Key 查看以及追加/替换到主账号都只读取数据库缓存，不再重复请求 NewAPI。
- 完整 Key 读取失败时整账号同步失败并保留旧缓存；Sub2API 的既有实时登录读取行为保持不变。
