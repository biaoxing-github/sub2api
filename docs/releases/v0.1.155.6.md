## 详细更新日志

1. `backend/migrations/177_add_newapi_checkin_api_key_cache.sql` 新增签到账号级 API Key 与分组缓存表，以签到账号外键保证账号删除时缓存同步清理。
2. `backend/internal/repository/newapi_checkin_repo.go` 增加缓存读取和幂等写入；页面摘要与仅供服务端引用匹配的 Key 信息分栏保存，完整匹配值不进入接口 JSON。
3. `backend/internal/service/newapi_checkin_service.go` 将普通目录读取改为数据库优先：缓存缺失时首次拉取并保存，未引用账号后续只读缓存，数据库已引用账号继续实时刷新。
4. 新增 `POST /api/v1/admin/newapi-checkin/api-keys/sync`，管理员手动同步时全量拉取全部启用账号的最新 API Key 和分组并更新缓存。
5. 追加或替换主平台账号 Key 前强制实时读取目标签到账号；修改上游分组成功后重新拉取并回写缓存，避免页面继续展示旧分组。
6. `frontend/public/newapi-checkin/index.html` 和 generated 管理端副本改用独立同步接口，并显示本次全量更新账号数。
7. service、repository、handler/routes 和前端测试覆盖缓存命中、缓存缺失、引用实时刷新、手动同步、JSONB round-trip 及服务端匹配 Key 不泄露。

## 用户可见行为

- 打开平台目录时，不再每次为所有账号请求上游；未引用账号直接显示数据库最近一次同步结果。
