## 详细更新日志

1. `backend/internal/service/newapi_checkin_service.go` 改为使用上游脱敏 Key 的可见前后缀匹配主平台账号数据库中的完整 Key，修复数据库已引用但页面无法识别的问题。
2. 引用识别不再依赖站点 URL 完全一致；数据库 Key 决定已引用关系，兼容站点 URL 决定可执行追加或替换的目标账号。
3. `dawclaudecode.com` 与 `api.dawclaudecode.com` 在协议、端口和规范化路径一致时视为兼容站点，`dawcode` 可作为关联目标。
4. 已引用生成 Key、目标账号和签到账号在返回结果中稳定置顶；前端平台目录同步置顶并显示绿色高亮和“数据库已引用 · 账号名”。
5. 上游只返回脱敏 Key 时，“显示完整 Key”、追加和替换会从数据库解析唯一完整 Key；找不到或匹配到多个不同完整 Key 时拒绝写入脱敏值。
6. `backend/internal/service/newapi_checkin_service_test.go` 与前端 Vitest 增加脱敏 Key、`api.` 子域名、完整 Key 解析、引用置顶和渲染顺序覆盖；本轮没有数据库 schema 或数据迁移。
