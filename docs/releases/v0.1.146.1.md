## 详细更新日志

- 后端 `backend/internal/handler/admin/token_cost_handler.go` 修正 `POST /admin/token-cost/state` 的响应结构，保存后返回规范化后的 `state` 对象，不再返回字符串状态占位。
- 前端新增 `frontend/src/api/admin/tokenCost.ts`，并在 `frontend/src/types/index.ts` 增加 Token 成本状态、平台、历史和事件的 TypeScript 类型。
- `frontend/src/views/admin/tools/TokenCostTool.vue` 改为通过 typed admin API service 注入 Legacy 工具运行时。
- `frontend/src/views/admin/tools/LegacyHtmlTool.vue` 与 `legacyToolRuntime.ts` 增加 service 注入能力，避免工具页直接手写 fetch、auth refresh 和缓存读取。
- `frontend/src/views/admin/tools/tokenCostLegacy.generated.ts` 移除旧 `STORAGE_KEY`、`localStorage` 成本状态缓存和静态默认大状态，页面启动后直接调用注入的 `tokenCostService.health/loadState/saveState`。
- `frontend/public/token-cost/index.html` 移除嵌入式静态 16 平台默认状态；独立页改为请求 `/api/v1/admin/token-cost/state?_=` 并带 cache-busting 参数，每次从服务端获取最新状态。
- 用户可见行为：管理端“API Token 余额动态计算器”不再优先显示浏览器缓存里的 16 条平台数据，进入页面会从后端动态接口读取数据库中的最新 21 条平台数据。
