## Detailed Changelog

Compared with `v0.1.136.18`, this release normalizes the account-test display text for OpenAI upstream overload responses.

1. Normalize overloaded upstream text in account tests
   - Modules: `backend/internal/service/account_test_service.go`
   - Change: account-test error sending now passes raw upstream errors through `accountTestDisplayError`.
   - User-visible impact: when an OpenAI test stream reports `server_is_overloaded` or `Our servers are currently overloaded. Please try again later.`, the account-test UI displays `上游服务繁忙，请稍后重试` instead of the upstream English message.

2. Preserve diagnostic fidelity in server logs
   - Modules: `backend/internal/service/account_test_service.go`
   - Change: `sendErrorAndEnd` still logs the original upstream message before sending the normalized display message.
   - User-visible impact: administrators no longer see the confusing English upstream message in test results, while operators can still inspect the raw upstream reason in application logs.

3. Add regression coverage for OpenAI Responses SSE failures
   - Modules: `backend/internal/service/account_test_service_openai_test.go`
   - Change: added a test for `response.failed` SSE payloads whose error code/message indicate overloaded upstream service.
   - User-visible impact: future changes to the OpenAI account-test stream parser will fail tests if they re-expose the raw overloaded English text.
