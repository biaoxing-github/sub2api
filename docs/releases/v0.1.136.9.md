## 详细更新日志

相较 `v0.1.136.8`，本版本聚焦修复 free-rawchat / OpenAI API Key Codex 模拟请求在客户端透传 `Accept: */*` 时被上游判定为 `codex_access_restricted` 的问题，并补齐 rawchat 相关入口的 Codex 稳定请求策略。

1. Codex 模拟强制覆盖 Accept
   - 涉及模块：`backend/internal/service/openai_gateway_service.go`。
   - 变更内容：`ensureOpenAICodexClientMetadataHeaders` 不再只在 `Accept` 为空时设置 `text/event-stream`，而是对 Codex 模拟路径无条件写入 `Accept: text/event-stream`。
   - 用户可见影响：API Key 账号开启 `openai_codex_cli_simulation_enabled=true` 时，即使客户端发送 `Accept: */*`，上游也会收到 Codex 期望的 SSE Accept 头，降低触发 `codex_access_restricted` 的概率。

2. 探测路径复用 Codex 模拟头
   - 涉及模块：`backend/internal/service/account_probe.go`。
   - 变更内容：OpenAI API Key 账号体检在启用 Codex 模拟时调用统一的 `applyOpenAICodexSyntheticClientHeaders`，补齐 UA、originator、会话和 turn metadata 头。
   - 用户可见影响：管理端账号体检与真实网关请求使用一致的 Codex 模拟指纹，避免体检和实际请求行为分叉。

3. rawchat / chat fallback 入口复用稳定上游发送策略
   - 涉及模块：`backend/internal/service/openai_gateway_chat_completions.go`、`backend/internal/service/openai_gateway_chat_completions_raw.go`、`backend/internal/service/openai_gateway_responses_chat_fallback.go`。
   - 变更内容：raw chat、chat-completions 转 responses、responses 强制 chat fallback 三条路径改用 `doOpenAIUpstreamWithHeaderTimeout`，并在真实 Codex 或账号级 Codex 模拟时启用 `openAICodexStabilityPolicy`。
   - 用户可见影响：free-rawchat 这类 Codex 模拟账号在等待上游响应头时使用同一套超时和 TLS profile 策略，降低不同入口之间的行为差异。

4. 回归测试覆盖
   - 涉及模块：`backend/internal/service/openai_gateway_service_test.go`、`backend/internal/service/account_probe_test.go`、`backend/internal/service/openai_gateway_chat_completions_test.go`、`backend/internal/service/openai_gateway_chat_completions_raw_test.go`、`backend/internal/service/openai_gateway_responses_chat_fallback_test.go`。
   - 变更内容：新增 `TestOpenAIBuildUpstreamRequestAPIKeyCodexSimulationOverridesWildcardAccept`，并覆盖账号体检、chat-completions、rawchat 和 fallback 的 Codex 模拟头 / TLS profile 行为。
   - 用户可见影响：后续若再次让客户端 `Accept: */*` 泄漏到 Codex 模拟上游请求，单元测试会直接失败。

## 回滚方式

如出现健康检查失败、panic/fatal、迁移错误、端口绑定失败或网关请求大面积失败，立即将 `D:\sub2api-deploy\proxy\upstreams\active.conf` 改回：

```nginx
upstream sub2api_active {
  server sub2api-green:8080;
  keepalive 32;
}
```

然后执行：

```powershell
docker exec sub2api-proxy nginx -t
docker exec sub2api-proxy nginx -s reload
```
