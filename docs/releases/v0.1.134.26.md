## 更新内容

- 现场日志确认报错来自 Anthropic 原生 `/v1/messages`：`api_key_id=2`、`group_id=1`、账号 `445(君公益)`，`platform=anthropic`、`type=apikey`。
- DB 快照确认账号 `445` 属于组 `1`，状态 active/schedulable，且 `extra.anthropic_passthrough` 为空；真实路径是 `GatewayService.Forward` 普通 Anthropic API Key 分支，不是 OpenAI 兼容路径，也不是 API Key 透传分支。
- 当 Anthropic 上游返回 HTTP 400，错误消息包含 `There was an issue with the format or content of your request` 且带 `request id` 时，在写客户端前返回 `UpstreamFailoverError`，让 handler 继续切换账号。
- 同一窄匹配也覆盖 Anthropic API Key 透传分支，避免未来开启 `anthropic_passthrough` 后再次直写客户端。
- 普通参数类 400 仍走默认错误响应，不会被误判为可切换账号。
