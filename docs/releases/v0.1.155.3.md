## 详细更新日志

1. `newapi_checkin_accounts` 增加 `login_username` 与 `login_password` 字段，迁移文件为 `backend/migrations/176_add_newapi_checkin_login_credentials.sql`；字段均为 `NOT NULL DEFAULT ''`，现有账号无损迁移。
2. NewAPICheckin service 增加 sub2api 账号登录流程：使用 `/api/v1/auth/login` 获取临时 JWT，再读取 `/api/v1/keys` 与 `/api/v1/groups/available`；JWT 不写入数据库或配置摘要。
3. 管理 API 增加登录凭据保存、登录测试、完整 API Key 读取和 Key 分组更新入口；配置摘要只返回登录账号与 `has_login_password`，不返回密码。
4. sub2api Key 分组更新使用上游真实 `group_id`，NewAPI 继续使用现有 token 分组名称；完整 Key 默认脱敏，仅在管理员主动点击后读取。
5. 平台目录增加独立“登录凭据”弹窗，支持填写邮箱/账号、密码、测试登录和验证后保存；密码字段不会从服务端回填到页面。
6. 前端公共 HTML 与 `newapiCheckinLegacy.generated.ts` 同步，类型与 Vitest 覆盖凭据提交、密码不回显、完整 Key 展示和 group_id 更新载荷。
