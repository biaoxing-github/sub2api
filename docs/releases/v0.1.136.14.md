## 详细更新日志

相较 `v0.1.136.13`，本版本把 Anthropic 风格请求的 Claude CLI 版本从“全局跟随当前服务端版本”扩展成“按账号自定义覆盖”。这样不同账号可以分别模拟不同的 Claude CLI 版本，不再因为一个账号需要旧版本头而影响所有 Anthropic/Antigravity 账号。

1. 后端新增账号级 `claude_cli_version` 覆盖
   - 涉及模块：`backend/internal/service/account.go`
   - 变更内容：新增账号凭证键 `claude_cli_version`，并提供 `GetClaudeCLIVersion()`。当账号凭证内写入合法 `X.Y.Z` 版本时优先使用该值；为空或非法时回退当前全局 Claude CLI 版本。
   - 用户可见影响：账号可以自己决定对上游声明的 Claude CLI 版本，不必跟随服务端统一版本。

2. Anthropic 账号测试、模型同步和 mimic 头全部改为按账号取版本
   - 涉及模块：`backend/internal/service/account_test_service.go`、`backend/internal/service/gateway_service.go`、`backend/internal/service/upstream_models.go`
   - 变更内容：Anthropic 账号测试 payload、session `user_id`、默认 OAuth 头、Claude Code mimic 头、billing block `cc_version`、metadata `user_id` 版本边界，以及 Anthropic/Antigravity 模型同步请求都改为优先使用 `account.GetClaudeCLIVersion()`。
   - 用户可见影响：同一台网关上的不同账号现在可以分别发出不同版本的 Claude CLI 头部形状，例如某个账号继续使用 `claude-cli/2.1.126 (external, cli)`，另一个账号则使用更新版本。

3. 管理端创建/编辑账号表单新增 Claude CLI 版本输入项
   - 涉及模块：`frontend/src/components/account/AccountAPIKeyCredentialsFields.vue`、`frontend/src/components/account/CreateAccountModal.vue`、`frontend/src/components/account/EditAccountModal.vue`、`frontend/src/i18n/locales/en.ts`、`frontend/src/i18n/locales/zh.ts`
   - 变更内容：Anthropic 与 Antigravity API Key 账号在创建/编辑时新增 `Claude CLI version` 输入框，写入 `credentials.claude_cli_version`。
   - 用户可见影响：管理员无需手改数据库或配置文件，直接在账号表单里就能按账号设置目标版本。

4. 回归测试覆盖账号级版本覆盖链路
   - 涉及模块：`backend/internal/service/account_claude_cli_version_test.go`、`backend/internal/service/account_test_service_claude_version_test.go`、`backend/internal/service/gateway_prompt_test.go`、`backend/internal/service/upstream_models_test.go`、`frontend/src/components/account/__tests__/AccountAPIKeyCredentialsFields.spec.ts`、`frontend/src/components/account/__tests__/EditAccountModal.spec.ts`
   - 变更内容：新增和更新测试，覆盖账号级版本校验、Anthropic 账号测试请求、billing block `cc_version`、模型同步请求以及前端表单加载/保存行为。
   - 用户可见影响：后续若账号级版本透传退化成全局值或前端忘记保存该字段，聚焦测试会直接失败。

## 回滚方式

如切流后出现健康检查失败、panic/fatal、迁移错误、端口绑定失败、网关请求大面积失败，立即把 `D:\sub2api-deploy\proxy\upstreams\active.conf` 改回：

```nginx
upstream sub2api_active {
  server sub2api-green:8080;
  keepalive 32;
}
```

然后执行：

```powershell
docker exec sub2api-proxy nginx -t
docker exec sub2api-proxy nginx -s reload
```
