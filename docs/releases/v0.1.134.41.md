## 更新内容

- 调度池人工测试成功后会恢复账号为可调度状态，并清除账号错误、限流、过载和临时不可调度状态。
- 后台自动探测成功仍不会自动打开管理员手动关闭的 `schedulable=false` 账号。
- hotaruapi API Key 的 Codex CLI 模拟请求头更新为真实客户端形状，使用 `originator=codex_cli_rs` 和 `x-codex-beta-features=compact-history`。
- OpenAI Responses SSE 探测流会识别上游裸 JSON 错误并透出真实错误消息，不再统一误报 `Stream ended before response.completed`。
- Gateway 流式解析支持从 `event:` 行识别 `response.completed` 终态，避免终态 `data` 缺少 `type` 时被误判为不完整。
- OpenAI API Key 账户探测遇到单个 `request_base_url` 的 EOF、超时等瞬态错误时会继续尝试下一个 base URL。
