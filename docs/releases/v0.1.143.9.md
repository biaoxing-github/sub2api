1. 修复 Token 成本页旧缓存显示

   - 变更内容：覆盖“旧 localStorage 16 平台 + 首次管理 API 401 + refresh token 成功 + SQL 页面状态 21 平台”的路径。
   - 用户可见行为：防止后续改动再次让 Token 成本页在登录态过期时停留在旧平台数量。
