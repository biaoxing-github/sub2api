## 详细更新日志

1. 调度热路径与 OpenAI 调度器拆分
   - 涉及模块：`backend/internal/service/openai_account_scheduler.go`、`openai_scheduler_candidate.go`、`openai_scheduler_runtime_stats.go`、`openai_scheduler_sticky.go`、`gateway_service.go`、`gateway_handler.go`。
   - 变更内容：将 RuntimeStats、CandidateScoring、StickySession 从主调度器文件拆出；请求级调度快照复用账号索引、window cost 和 RPM 预取结果；privacy 未设置账号在热路径只跳过并记录运行时阻断，避免选号循环同步写库。
   - 用户可见影响：OpenAI/Claude/Gemini 转发入口行为保持一致，调度路径减少重复预取和同步写库开销。

2. Codex 与 Claude 客户端版本同步
   - 涉及模块：`backend/internal/pkg/openai/codex_version_fetcher.go`、`backend/internal/pkg/claude/constants.go`、`backend/internal/service/setting_service.go`。
   - 变更内容：Codex 默认版本更新为 `0.141.0`，Claude CLI UA 更新为 `2.1.181`；Codex 版本同步从本地 `codex --version` 改为读取 npm `@openai/codex/latest`，服务端没有本地 Codex 二进制时仍能同步版本。
   - 用户可见影响：OpenAI Codex CLI/Desktop 模拟请求头更贴近当前客户端版本，减少上游版本门槛误判。

3. 管理端 Settings 与账号页面组件化
   - 涉及模块：`frontend/src/views/admin/SettingsView.vue`、`frontend/src/views/admin/settings/*`、`frontend/src/components/account/*`、`frontend/src/components/admin/settings/*`、`frontend/src/components/admin/account/AccountAutoRefreshControl.vue`。
   - 变更内容：SettingsView 的 General、Agreement、Features、Security、Users、Gateway、Payment、Email tab 拆为独立组件；账号创建/编辑表单拆出基础信息、API Key 凭证、上游凭证、余额、模型限制、配额控制等公共组件；账号自动刷新和设置页保存栏/Tab 导航拆为复用组件。
   - 用户可见影响：页面行为保持不变，后续设置页和账号页维护边界更清晰，前端测试覆盖更细。

4. 支付状态轮询与静态落地页整理
   - 涉及模块：`frontend/src/components/payment/PaymentStatusPolling.ts`、`PaymentStatusPanel.vue`、`PaymentQRDialog.vue`、`PaymentQRCodeView.vue`、`static-landing/*`。
   - 变更内容：支付状态轮询逻辑独立成模块并补单测；新增静态 landing 页面源文件，删除旧 apishare 截图。
   - 用户可见影响：支付状态轮询逻辑更易复用和验证，静态页面资产改为可维护 HTML。

## 回滚方式

如出现健康检查失败、panic/fatal、迁移错误、端口绑定失败或网关请求大面积失败，立即将 `D:\sub2api-deploy\proxy\upstreams\active.conf` 改回：

```nginx
upstream sub2api_active {
  server sub2api-blue:8080;
  keepalive 32;
}
```

然后执行：

```powershell
docker exec sub2api-proxy nginx -t
docker exec sub2api-proxy nginx -s reload
```
