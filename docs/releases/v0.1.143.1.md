## Detailed Changelog

Compared with `v0.1.140.2`, this release absorbs the P0 stability and compatibility fixes from upstream `v0.1.142` and `v0.1.143`.

1. Anthropic streaming compatibility for Claude Code and thinking-disabled flows
   - Modules: `backend/internal/service/gateway_service.go`, `backend/internal/service/gateway_streaming_test.go`
   - Change: suppresses thinking blocks when the request disables thinking, and emits Claude Code noop delta keepalive for CLI versions `>= 2.1.193`.
   - User-visible impact: streaming keeps moving without dead air or protocol drift on newer Claude Code clients.

2. OpenAI gateway failover and retry hardening
   - Modules: `backend/internal/service/openai_gateway_service.go`, `backend/internal/service/openai_ws_forwarder.go`, `backend/internal/service/openai_ws_protocol_forward_test.go`, `backend/internal/service/openai_ws_ratelimit_signal_test.go`
   - Change: HTTP 413 is returned directly; pre-write WS failures for rate limit, auth, read, dial, acquire, event, and missing-final cases become failover; zero retry budget now exhausts immediately; `codex.rate_limits` events persist into account runtime limiting.
   - User-visible impact: fewer stale hangs and more predictable failover behavior when upstream rejects or throttles a request.

3. OpenAI API key and OAuth fallback compatibility
   - Modules: `backend/internal/service/openai_gateway_service.go`, `backend/internal/service/gateway_service.go`, `backend/internal/service/gateway_anthropic_apikey_passthrough_test.go`, `backend/internal/service/gateway_count_tokens_test.go`
   - Change: WS ingress records selected API key for cooldown isolation, OAuth `count_tokens` falls back to local estimation when upstream does not support it, and 413/429/401 paths stay isolated to the relevant key.
   - User-visible impact: one noisy key no longer drags the whole account down, and count-tokens remains usable on providers with weaker support.

4. Billing/model compatibility absorption
   - Modules: `backend/internal/service/billing_service.go`, `backend/internal/service/openai_codex_transform.go`, `backend/internal/service/openai_model_alias.go`, `backend/internal/service/openai_model_mapping_test.go`
   - Change: GPT-5.5 Pro is mapped and billed consistently; long-context cache creation/read prices scale with the same multiplier as input-side pricing.
   - User-visible impact: pricing and model routing stay consistent for the newer GPT-5.5 Pro family.

5. Antigravity and Claude OAuth request cleanups
   - Modules: `backend/internal/pkg/antigravity/request_transformer.go`, `backend/internal/repository/claude_oauth_service.go`
   - Change: reasoning-model requests avoid incompatible tool config and thinking parameters, while Claude OAuth token exchange stops adding unnecessary `expires_in`.
   - User-visible impact: fewer provider-side compatibility errors during model and OAuth operations.
