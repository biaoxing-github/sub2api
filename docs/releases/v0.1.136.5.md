## 更新内容

- 修正 OpenAI Codex CLI 模拟在“裸域名 base_url”场景下的 Responses 路径拼接：当账号启用 Codex CLI 模拟且 base_url 只有主机名时，测试链路和正式链路统一改为访问 `/v1/responses`，不再错误落到 `/responses`。
- 保留已有带路径 base_url 的行为：例如 `/codex` 这类自定义前缀仍继续拼成 `/codex/responses`，避免误伤已正常工作的上游代理路径。
- 管理端账号测试与账号探测新增协议级诊断：如果上游返回的是 HTML 或非 SSE 文本，而不是 `text/event-stream` 数据流，错误信息会明确提示 `non-SSE HTML response`，不再笼统报 `Stream ended before response.completed`。
- 对应单元测试覆盖了裸域名 `/v1/responses` 路径选择、非 SSE HTML 响应诊断，以及 EOF/[DONE] 终止兼容行为，确保同类问题可回归验证。
