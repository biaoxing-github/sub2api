## 详细更新日志

- 后端新增 Grok/xAI OAuth 服务链路，补齐 Grok OAuth client repository、token refresher、xAI OAuth HTTP helper 和 Wire 注入，使管理端可以生成授权链接、交换授权码、导入 refresh token 并刷新 access token。
- OpenAI-compatible 网关新增 Grok 平台上下文与账号筛选逻辑，`/responses`、`/v1/responses` 等 OpenAI 兼容入口可以按请求平台调度 Grok 账号，不再混用 OpenAI 账号池。
- Grok `/responses` 转发新增专用请求构建与模型字段清理，保留 xAI 兼容字段并移除不支持的 OpenAI Responses 字段，转发时使用 Grok 账号配置的 base URL 与 Bearer token。
- 后端新增 Grok API Key 支持：Grok API Key 账号从 `credentials.api_key` 读取 xAI Key，返回 token type `apikey`，与 OAuth token 路径并存。
- 管理端账号创建页新增 Grok 平台、Grok OAuth 流程、Grok API Key 类型选择、xAI API Key 输入提示和 `https://api.x.ai/v1` 默认 base URL。
- 管理端账号编辑和重新授权弹窗补齐 Grok 分支，Grok 账号会进入 xAI OAuth 重新授权路径，Grok API Key 账号编辑时展示 xAI base URL 提示并保持 Grok 默认地址。
- 账号组和后台类型定义补齐 Grok 平台常量、平台颜色、模型候选和 API 导出，前后端共享类型可以识别 `platform=grok`。
- 新增聚焦回归测试覆盖 Grok OAuth token、Grok API Key token、Grok Responses 请求构建、Grok 平台调度、Grok route 注册和 scheduler exhaustion probe 平台隔离。
- 用户可见行为：后台可以创建/编辑 Grok OAuth 或 Grok API Key 账号；配置成功后 OpenAI-compatible `/responses` 请求可以调度 Grok/xAI 账号。
