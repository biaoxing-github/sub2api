## Detailed Changelog

Compared with `v0.1.143.1`, this release ships the P1 low-conflict bugfix and metadata absorption from upstream `v0.1.142` and `v0.1.143`.

1. Account pagination query isolation
   - Modules: `backend/internal/repository/account_repo.go`, `backend/internal/repository/account_repo_integration_test.go`
   - Change: `ListWithFilters` now uses `q.Clone().Count(ctx)` before applying pagination.
   - User-visible impact: account list totals no longer mutate the later list query through Ent soft-delete predicates, reducing noisy SQL shape regressions and keeping list pagination stable.

2. OpenAI OAuth plan type preservation
   - Modules: `backend/internal/service/openai_oauth_service.go`, `backend/internal/service/openai_subscription_test.go`
   - Change: `accounts/check` plan type only fills an empty local plan type and no longer overwrites a plan type already obtained from the ID token.
   - User-visible impact: a personal plan detected from the token is not replaced by inactive workspace metadata during OAuth enrichment.

3. OpenAI OAuth subscription expiration persistence in the frontend
   - Modules: `frontend/src/composables/useOpenAIOAuth.ts`, `frontend/src/composables/__tests__/useOpenAIOAuth.spec.ts`
   - Change: `subscription_expires_at` is preserved from token exchange response into account credentials.
   - User-visible impact: subscription expiration metadata can survive the OAuth create/update path instead of being dropped in the browser layer.

4. Compact bridge duplicate skipped
   - Modules verified: `backend/internal/service/openai_gateway_service.go`
   - Change: no new code was needed because the local implementation already skips Codex image bridge injection for `/responses/compact`.
   - User-visible impact: compact requests keep the existing safer behavior, with the existing regression test still passing.
