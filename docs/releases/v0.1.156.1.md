## 详细更新日志

1. 调度池账号行新增优先级输入框和保存按钮，可直接临时调整账号优先级，保存后刷新调度池快照。
2. 最低数值优先级保持硬分层，最高优先级账号会先进入调度候选。
3. 同优先级账号先比较剩余并发槽，再比较负载率和 LRU，人工配置的并发容量会直接影响调度顺序。
4. OpenAI 综合评分的负载维度中，剩余并发容量占 70%，负载率占 30%，之后继续综合排队、错误率和首 token 延迟。

## 用户可见行为

- 管理员可在调度池页面直接调整账号优先级，无需跳转账号编辑页。
- 临时提高某个账号的优先级后，该优先级层会先于其他层调度。
- 同一优先级下，并发余量更大的账号更容易先接收请求，减少低容量账号被集中占满。
