## 更新内容

- 用真实 `@openai/codex@0.138.0 exec` 抓包结果校正账号级 Codex CLI 模拟：`User-Agent` 改为 `Codex Desktop/0.138.0 ... (codex_exec; 0.138.0)`，`originator` 改为 `Codex Desktop`。
- Codex CLI 模拟请求不再向上游注入旧 `OpenAI-Beta: responses=experimental` 和 `version` 请求头，避免触发“请使用最新版 codex 客户端或 codex cli 调用”的上游限制。
- 放行并补齐真实 Codex CLI 常用请求头：`Accept: text/event-stream`、`X-Codex-Beta-Features`、`session-id`、`thread-id`、`x-client-request-id`、`x-codex-window-id`、`x-codex-turn-metadata` 等。
- 管理端 OpenAI API Key 人工测试 payload 调整为接近真实 Codex Responses 请求，包含 `store=false`、`prompt_cache_key`、`reasoning.effort`、`text.verbosity` 和 `include=["reasoning.encrypted_content"]`，并继续复用正式网关 builder。

## 根因

- `free5` 已启用账号级 `openai_codex_cli_simulation_enabled=true`，但旧代码模拟的是过期 `codex_cli_rs` 指纹，并携带真实 `@openai/codex@0.138.0` 不再发送的实验头，导致上游仍判定为非最新版 Codex 客户端。
