## 更新内容

- OpenAI/Codex 上游 TLS 指纹触发范围改为账号级 `openai_codex_cli_simulation_enabled`。
- 全局 `OpenAIOAuthCompatMode=codex_direct` 不再触发普通 OAuth/APIKey 账号的 Codex TLS 模拟，减少全局覆盖风险。
- 管理端人工测试和正式 OpenAI 网关热路径统一复用账号级模拟规则：free5 这类 APIKey 账号会按账号开关启用 Codex Desktop 0.138.0 请求头和 Codex TLS profile。
- 更新单测，覆盖“全局 codex_direct 不生效、账号级模拟生效”的边界。

## 根因校正

- 真实 `@openai/codex@0.138.0 exec` 直连 free5 上游已验证可返回 `OK`。
- 本轮本地传输探针使用真实 Codex CLI 捕获 body/header 后直打 free5，上游对 Go 默认 TLS、内置 Node.js 24.x profile、Linux Node.js 22 profile 均返回 200，说明单纯 TLS profile 不是唯一拦截点。
