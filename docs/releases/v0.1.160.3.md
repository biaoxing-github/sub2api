## 功能与用户影响

- Codex 模拟客户端身份按上游 API Key 隔离：同一 Key 保持稳定，换 Key 后 installation、session、thread、window 和 prompt cache 身份同步变化。
- 切回曾使用的 Key 会恢复该 Key 的稳定身份；单次请求的 turn ID 和 client request ID 仍逐次变化。
- OpenAI WebSocket 连接只有在 Authorization、目标地址、代理和 beta 特性摘要一致时复用，避免新 Key 复用旧 Key 建立的连接。
