## 功能与用户影响

- OpenAI OAuth passthrough 可将字符串、对象和数组形态的 `input` 统一为上游要求的数组；空字符串保持为空数组，既有 `compact`、`store` 与 `stream` 语义不变。
- Grok 账号收到上游 HTTP 402 后仅对当前账号写入 30 分钟临时不可调度状态，不扩大为全局或其他账号熔断。
- 更新 Codex 导入账号时会清理更新前的用户、访问令牌和账户身份索引，旧身份键不会继续命中该账号。
- Claude 模型名的点号与连字符写法使用同一定价；CC Switch 的 Grok 导入进入 Grok Build 并规范化 `/v1` 路径，限流状态展示精确到恢复日期和分钟。

## 涉及模块

- `backend/internal/service/openai_gateway_service.go`、`openai_gateway_grok.go`：OAuth 输入归一化与 Grok 402 调度冷却。
- `backend/internal/handler/admin/account_codex_import.go`：Codex 导入身份索引更新清理。
- `backend/internal/service/channel_service.go`：Claude 模型名定价归一化。
- `frontend/src/utils/ccswitchImport.ts`、`frontend/src/utils/format.ts`、`frontend/src/components/account/AccountStatusIndicator.vue`：Grok 导入与限流恢复时间显示。
