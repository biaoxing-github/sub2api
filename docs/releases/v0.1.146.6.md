1. Grok 账号可编入 OpenAI 分组：

## 回滚方案

如出现健康检查失败、panic/fatal、迁移错误、端口绑定失败或 OpenAI 兼容请求大面积异常，立即将 `D:\sub2api-deploy\proxy\upstreams\active.conf` 从 `sub2api-green:8080` 切回 `sub2api-blue:8080`，执行：

```powershell
docker exec sub2api-proxy nginx -t
docker exec sub2api-proxy nginx -s reload
```

回滚后以 `sub2api-blue` 上的 `sub2api:v0.1.146.5` 作为线上版本。
