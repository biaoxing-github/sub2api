## 详细更新日志

相较 `v0.1.136.6`，本版本是一次聚焦 rawchat / chat-completions Codex 模拟头的修复发布。

1. rawchat 网关路径复用 Codex CLI/Desktop 模拟头
   - 涉及模块：`backend/internal/service/openai_gateway_chat_completions_raw.go`。
   - 变更内容：`forwardAsRawChatCompletions` 构造上游请求后调用 `applyOpenAICodexCLISimulationHeaders`，与常规 `/responses` 热路径保持同一套 Codex 客户端模拟头。
   - 用户可见影响：用户通过 rawchat 走 `/v1/chat/completions` 时，上游不再因为缺少最新版 Codex CLI/Desktop 模拟请求头而误判为旧客户端。

2. `/responses` 强制 chat-completions fallback 路径同步修复
   - 涉及模块：`backend/internal/service/openai_gateway_responses_chat_fallback.go`。
   - 变更内容：`forwardResponsesViaRawChatCompletions` 在 fallback 到 chat-completions 体之后同样注入 Codex 模拟头。
   - 用户可见影响：开启或触发 raw chat fallback 的 `/responses` 请求与直接 rawchat 请求保持一致，不再只在正常 `/responses` 路径可用。

3. 管理端账号测试 chat-completions 路径同步修复
   - 涉及模块：`backend/internal/service/account_test_service.go`。
   - 变更内容：OpenAI API Key chat-completions 账号测试路径复用 `OpenAIGatewayService.applyOpenAICodexCLISimulationHeaders`，并临时补齐默认 Codex 入站客户端头后再构造上游请求。
   - 用户可见影响：管理端账号测试与实际网关 rawchat 行为一致，避免测试按钮仍返回 `codex_access_restricted`。

4. 回归测试覆盖
   - 涉及模块：`backend/internal/service/account_test_service_openai_test.go`、`backend/internal/service/openai_gateway_chat_completions_raw_test.go`、`backend/internal/service/openai_gateway_responses_chat_fallback_test.go`。
   - 变更内容：新增三个聚焦测试，分别覆盖管理端账号测试、rawchat 网关、`/responses` 强制 chat fallback 的 Codex 模拟头注入。
   - 用户可见影响：后续修改 rawchat 或账号测试请求构造时，会直接触发单元测试防止回归。

## 回滚方式

如出现健康检查失败、panic/fatal、迁移错误、端口绑定失败或网关请求大面积失败，立即将 `D:\sub2api-deploy\proxy\upstreams\active.conf` 改回：

```nginx
upstream sub2api_active {
  server sub2api-green:8080;
  keepalive 32;
}
```

然后执行：

```powershell
docker exec sub2api-proxy nginx -t
docker exec sub2api-proxy nginx -s reload
```
