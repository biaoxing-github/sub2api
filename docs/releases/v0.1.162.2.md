## 功能与用户影响

- 管理员创建 OpenAI OAuth 账号时，可在既有授权导入流程中选择 Agent Identity 内容；它不是额外账号类型，也不会暴露未接通的其他导入入口。
- Agent Identity 导入复用现有 Codex session 导入请求，导入内容在服务端按 ChatGPT Team 隔离：同一 Team 的再次导入更新运行时信息，不同 Team 的同一用户保持独立账号。
- OpenAI Chat Completions、Responses、Messages、图片和 WebSocket 相关路径能够继续使用已导入的 Agent Identity 凭据。

## 涉及模块

- `backend/internal/handler/admin`：Agent Identity 导入编排、Team 维度去重与回归测试。
- `backend/internal/service`：凭据解析、账号运行时、使用量、网关和 WebSocket 适配。
- `frontend/src/components/account`、`frontend/src/composables`、`frontend/src/i18n`：OpenAI OAuth 页内导入选项、说明文案和前端回归测试。
