## 功能与用户影响

- OpenAI Responses 请求触发调度耗尽恢复时，恢复探针继承原请求的 `stream` 模式。
- 流式探针使用 SSE 协议，并且只有收到 `response.completed` 或 `response.done` 成功终态才恢复账号调度。
- 失败、不完整、取消、错误、畸形、空流、仅 `[DONE]` 或缺少成功终态均保持探针失败；非流式 JSON 探针行为不变。
