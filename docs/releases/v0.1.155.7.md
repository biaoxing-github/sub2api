## 详细更新日志

1. `backend/internal/service/newapi_checkin_service.go` 在普通平台目录读取时，除缓存生成 Key 外，同时使用签到账号自身 access key 判断其是否已被主平台账号引用。
2. 已引用账号即使数据库中只有旧 `unsupported` 缓存，也会实时登录对应 sub2api 站点读取最新 Key 和分组，并覆盖账号级 PostgreSQL 缓存。
3. 未引用且已有缓存的账号继续只读数据库，不增加上游请求；手动“同步 Key / 分组”继续强制刷新全部启用账号并持久化。
4. 保存 sub2api 登录凭据时复用本次验证登录已经读取到的 Key 和分组，同步写入 `newapi_checkin_api_key_cache`，不再保留保存前的旧状态。
5. `backend/internal/service/newapi_checkin_service_test.go` 新增旧 `unsupported` 缓存恢复测试，并增强登录凭据保存后的缓存持久化断言。
