## 详细更新日志

相较 `v0.1.136.12`，本版本继续收口 Codex Desktop 模拟头，去掉“桌面 build 位写死成版本号自身”的错误形状，并让网关在见到真实 Codex Desktop 请求后，自动学习其 build 位用于后续 API Key 模拟。

1. Codex Desktop 模拟头改为真实桌面 UA 形状
   - 涉及模块：`backend/internal/pkg/openai/codex_version_fetcher.go`、`backend/internal/pkg/openai/codex_version_fetcher_test.go`、`backend/internal/service/openai_gateway_service_codex_cli_only_test.go`
   - 变更内容：`CodexCLIUserAgentForVersion(...)` 不再把尾段写成 `(codex_exec; <version>)` 或 `(Codex Desktop; <version>)` 这种错误回显，而是生成 `Codex Desktop/<version> (Windows 10.0.26200; x86_64) unknown (Codex Desktop; <build>)` 的真实桌面形状。
   - 用户可见影响：网关模拟出的 Codex Desktop 请求头更贴近真实客户端，减少因客户端身份形状异常被上游策略拒绝的概率。

2. 从真实 Codex Desktop 请求动态学习 build 位
   - 涉及模块：`backend/internal/pkg/openai/codex_version_fetcher.go`、`backend/internal/service/openai_gateway_service.go`
   - 变更内容：新增真实 `Codex Desktop/... (Codex Desktop; build)` UA 的 build 提取、观察和进程内缓存逻辑；当网关识别到真实 Codex Desktop 请求时，会先学习该 build 位，再继续构造 API Key 模拟头。
   - 用户可见影响：后续 API Key 模拟头不再只能依赖固定回退值；只要当前进程见过新的真实 Desktop 客户端，模拟头就会自动跟随最新 build。

3. 回归测试覆盖学习后的 HTTP/WS 模拟链路
   - 涉及模块：`backend/internal/pkg/openai/codex_version_fetcher_test.go`、`backend/internal/service/openai_gateway_service_test.go`
   - 变更内容：新增测试覆盖 build 提取、忽略非 Desktop UA、学习后模拟 UA 跟随新 build，以及真实 Desktop UA 入站后 HTTP 模拟请求带出新 build。
   - 用户可见影响：后续若再退回到旧的写死逻辑或错误 UA 形状，聚焦测试会直接失败。

## 回滚方式

如切流后出现健康检查失败、panic/fatal、迁移错误、端口绑定失败、网关请求大面积失败，立即把 `D:\sub2api-deploy\proxy\upstreams\active.conf` 改回：

```nginx
upstream sub2api_active {
  server sub2api-blue:8080;
  keepalive 32;
}
```

然后执行：

```powershell
docker exec sub2api-proxy nginx -t
docker exec sub2api-proxy nginx -s reload
```
