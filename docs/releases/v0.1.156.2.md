## 详细更新日志

1. `backend/internal/service/newapi_checkin_service.go` 修复签到工具向主平台账号追加或替换 Key 时错误删除 `base_url` 的问题。
2. 根因是 `LinkAPIKeyToAccount` 把仅包含 Key 字段的局部更新传给完整表单合并器；该合并器会按设计删除未提交的非敏感字段，因此 `base_url`、`model_mapping` 等配置被一起清空。
3. 新实现先复制目标账号的完整 credentials，再写入 `api_keys_append` 或 `api_keys` 并执行既有 Key 规范化，只改变 Key 相关字段。
4. replace 操作继续删除 `api_keys_disabled`，原有禁用指纹清理语义保持不变。
5. `backend/internal/service/newapi_checkin_service_test.go` 增加 append/replace 后站点 URL、最终 OpenAI 请求地址、模型映射和禁用指纹的回归断言。
6. `AGENTS.md` 同步精简发布操作手册，并固定最新 tag、不可变镜像、版本注入、蓝绿观察和数据保护闸门。
