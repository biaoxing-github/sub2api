## 详细更新日志

1. 月度签到账号日去重
   - 涉及 `backend/internal/service/newapi_checkin_service.go`。
   - `aggregateMonthly` 在生成站点月、账号月、站点日和账号日汇总前，按 `site + user_id + checkin_date` 收敛重复记录。
   - 重复键采用本次输入中最新记录，避免同一账号同一天被重复计算签到次数和奖励。
   - 用户可见行为：重复刷新月度历史后，每个账号每天最多显示一次签到，奖励也只计一次。

2. 回归测试
   - 涉及 `backend/internal/service/newapi_checkin_service_test.go`。
   - 新增 `TestAggregateMonthlyCountsEachAccountDayOnce`，同时覆盖站点月度、账号月度、站点每日和账号每日四类汇总。
   - 修复前测试明确失败为 `expected 1, actual 2`；修复后四类汇总均为一次签到和一次奖励。

3. 数据与 schema 边界
   - `newapi_checkin_monthly_records` 继续使用既有 `UNIQUE (site, user_id, checkin_date)` 保证物理存储唯一。
   - 发布前线上核对为 461 行、461 个唯一账号日键、0 个重复组。
   - 本轮无 migration、schema 或历史数据删除，不重启 PostgreSQL 和 Redis。
