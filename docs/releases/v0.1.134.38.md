## 更新内容

- 停用 OpenAI OAuth 的 `cockpit-tools` 全局兼容模式：旧 `openai_cockpit_tools_compat=true` 和 `openai_oauth_compat_mode=cockpit_tools` 只作为历史配置读取，运行时统一归一为 `off`。
- 移除管理端设置页里的 Cockpit Tools 可见选项，保存设置时固定写回 `openai_oauth_compat_mode=off` 与 `openai_cockpit_tools_compat=false`。
- 取消 cockpit 模式对 OAuth 上游 WS/HTTP 决策和请求头重建的影响，OAuth 请求继续走 sub2api 默认路径；账号级 Codex CLI 模拟能力不受影响。
- 保留并验证 API Key `request_base_urls` 在请求阶段 transient transport error 时先切换同账号下一个 base URL，再进入账号 failover。

## 回滚

如新版本出现健康检查失败、panic/fatal、迁移错误、端口绑定失败或网关请求大面积失败，将 `D:\sub2api-deploy\proxy\upstreams\active.conf` 切回 `server sub2api-blue:8080;`，执行 `docker exec sub2api-proxy nginx -t` 与 `docker exec sub2api-proxy nginx -s reload`。
