## Detailed Changelog

Compared with `v0.1.136.19`, this release improves Codex/OpenAI client compatibility in two user-visible areas: interrupted Responses streams now end with a protocol failure event, and OpenAI account credentials can override the simulated Codex CLI User-Agent.

1. Mark interrupted Responses streams as failed instead of completed
   - Modules: `backend/internal/service/openai_gateway_service.go`, `backend/internal/service/openai_gateway_service_test.go`, `backend/internal/handler/openai_gateway_handler_test.go`
   - Change: when upstream has already emitted partial `response.output_text.delta` data but never sends a terminal `response.completed`, `response.failed`, `response.incomplete`, or `response.cancelled` event, the gateway now writes a Responses-compatible `response.failed` terminal event.
   - User-visible impact: Codex clients no longer display a half-interrupted conversation as if it completed successfully.

2. Add account-level Codex CLI User-Agent override
   - Modules: `backend/internal/service/account.go`, `backend/internal/service/openai_gateway_service.go`, `backend/internal/service/openai_ws_forwarder.go`, `backend/internal/service/account_test_service_openai_test.go`
   - Change: OpenAI credentials now support `openai_codex_cli_user_agent`. HTTP Responses forwarding, WebSocket forwarding, and OpenAI account-test Responses requests prefer this account value when Codex CLI simulation is enabled.
   - User-visible impact: each OpenAI account can simulate a specific Codex Desktop/CLI request header such as `Codex Desktop/0.142.2 (Windows 10.0.26200; x86_64) unknown (Codex Desktop; 26.623.30605)`.

3. Expose the new User-Agent field in the admin account UI
   - Modules: `frontend/src/components/account/AccountAPIKeyCredentialsFields.vue`, `frontend/src/components/account/CreateAccountModal.vue`, `frontend/src/components/account/EditAccountModal.vue`, `frontend/src/i18n/locales/zh.ts`, `frontend/src/i18n/locales/en.ts`
   - Change: API Key and OAuth OpenAI account create/edit flows can set or clear the Codex CLI User-Agent override.
   - User-visible impact: administrators can configure the request simulation string per account without changing environment variables or code.

4. Add regression coverage
   - Modules: `backend/internal/service/account_openai_passthrough_test.go`, `backend/internal/service/account_test_service_openai_test.go`, `frontend/src/components/account/__tests__/AccountAPIKeyCredentialsFields.spec.ts`, `frontend/src/components/account/__tests__/EditAccountModal.spec.ts`
   - Change: tests cover configured UA forwarding, default UA fallback, account-test headers, interrupted stream failure termination, field rendering, update events, and edit-save payloads.
   - User-visible impact: future changes to Codex simulation or Responses stream termination should fail focused tests before they can silently regress.
