## 功能与用户影响

- OpenAI/Codex API Key 账号在默认 TLS 配置下，按 Sub2API 账号 ID 稳定分配十套实际互异的 uTLS ClientHello。
- 同一账号的 HTTP 与 WebSocket 上游连接使用同一套 TLS 模板；账号、TLS Profile 或 Authorization 变化时，底层连接身份同步隔离。
- 管理员显式选择数据库模板时仍优先使用指定模板，随机模板语义保持不变。
