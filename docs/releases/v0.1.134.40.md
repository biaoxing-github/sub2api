## 更新内容

- OpenAI 与 Anthropic 异常账号同账号探测统一限制为首次请求加一次重试，重试间隔固定 30 秒。
- handler 在同账号等待或切号前写入账号级临时冷却，避免并发请求继续命中同一异常账号。
- Anthropic 服务层内部重试耗尽后不再把同账号重试委托给 handler，避免形成第三次同账号探测。
- OpenAI 与 Anthropic API Key 的 `request_base_urls` 在 5xx/transport 错误时不再同一账号内快速扫多个 base URL。
- OpenAI WS 重连上限收敛为 1 次，退避强制 30 秒下限。
