## 详细更新日志

1. 吸收 v0.1.147 网关稳定性改进：
   - 涉及模块：`backend/internal/service/gateway_service.go`、`backend/internal/service/account.go`、`backend/internal/service/billing_service.go`、`backend/internal/service/ratelimit_service.go`。
   - 用户可见行为：无 `gin.Context` 的后台转发/count_tokens 错误路径不再 panic；OpenAI OAuth 空映射不再错误吸收第三方模型；渠道价格覆盖不污染共享 fallback；Anthropic 无 reset 头 429 进入短时冷却。

2. 增加 OpenAI 首字节慢路径降权和输出前切换：
   - 涉及模块：`backend/internal/service/openai_path_health.go`、`backend/internal/service/openai_gateway_service.go`、`backend/internal/service/openai_scheduler_candidate.go`。
   - 用户可见行为：慢首字节账号/baseURL 会被短期降权；真实输出前的请求阶段超时可切换下一候选，已经输出内容或客户端取消后不做透明切换。

3. 吸收 v0.1.149 compact JSON 到 Responses SSE 桥接：
   - 涉及模块：`backend/internal/handler/openai_gateway_handler.go`、`backend/internal/service/openai_compact_body_signal.go`、`backend/internal/service/openai_compact_stream_bridge.go`。
   - 用户可见行为：body-signal compact 且客户端请求 `stream:true` 时，unary JSON 会转换为标准 `response.output_item.done`、`response.completed` 和 `[DONE]` 事件；路径型 compact 和错误响应保持原语义。

4. 对齐 `response.failed` 语义、失败用量和错误透传：
   - 涉及模块：`backend/internal/service/openai_response_failed_passthrough.go`、`openai_gateway_chat_completions.go`、`openai_gateway_messages.go`、`backend/internal/handler/openai_chat_completions.go`。
   - 用户可见行为：Responses、Chat Completions、Messages 保留失败事件中的部分 usage；已观察到 token/图片用量的失败尝试进入既有计费链路且只提交一次；已写出的 JSON/SSE 语义错误不再叠加泛化错误体。

5. 同步本机 Codex 最新 GPT-5.6 模型和思考强度：
   - 涉及模块：`frontend/src/components/keys/UseKeyModal.vue`、`backend/internal/service/openai_gateway_service.go`。
   - 用户可见行为：OpenCode 配置包含 `gpt-5.6-sol`、`gpt-5.6-terra`、`gpt-5.6-luna`，上下文均为 `372000`；Sol/Terra 支持到 `ultra`，Luna 支持到 `max`；usage 归一化保留 `max/ultra`。

6. 补齐兼容协议和上游请求清理：
   - 涉及模块：`backend/internal/pkg/apicompat`、`backend/internal/pkg/httputil`、`backend/internal/service/gateway_websearch_block_filter.go`、`backend/internal/service/openai_codex_transform.go`。
   - 用户可见行为：Chat/Responses 结构化输出可双向转换；Anthropic 上游会移除不兼容的历史 Web Search 块；Codex 非法 call-input ID 被清理；`namespace=image_gen` 和 lenient JSON body 得到支持。

7. 修复 Google API Key 鉴权一致性：
   - 涉及模块：`backend/internal/server/middleware/api_key_auth_google.go`。
   - 用户可见行为：Google 兼容入口执行 IP 黑白名单、过期、额度耗尽和分组可用性检查，并返回对应 403/429 语义。

8. 修复支付轮询、路由守卫和本地登出状态：
   - 涉及模块：`frontend/src/components/payment/PaymentStatusPanel.vue`、`frontend/src/views/user/PaymentQRCodeView.vue`、`StripePopupView.vue`、`frontend/src/router/index.ts`、`frontend/src/stores/auth.ts`、`frontend/src/api/client.ts`。
   - 用户可见行为：支付轮询不再并发重入；Stripe popup 正确清理监听器/计时器并读取现行 token；支付路由先加载公共设置；服务端登出失败仍清除本地会话；refresh 请求有 30 秒超时。

9. 延长 CRS 同步请求超时：
   - 涉及模块：`frontend/src/api/admin/accounts.ts`。
   - 用户可见行为：大量账号的 CRS 同步请求允许等待 180 秒，不再被默认前端超时提前中断。

10. 数据边界：
    - 本次没有 migration、SQL、Ent schema 或新表，也没有历史数据迁移。
    - 失败用量继续写入既有 usage、余额和配额链路。
