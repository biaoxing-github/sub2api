## P0 验收标准

- compact body-signal + `stream:true` 返回合法 Responses SSE，包含每个 output item 的 `response.output_item.done` 和最终 `response.completed`。
- compact path-based unary 请求保持 JSON，不被错误转换。
- compact 非 2xx 错误保持原 HTTP 状态和 JSON 错误体。
- `response.failed` 的关键词规则和错误码规则在 Responses、passthrough、Chat Completions、Messages 四类路径都能命中。
- Grok 账号按 `grok` 平台规则匹配，不误用 OpenAI 平台规则。
- 命中透传规则后仍记录 Ops 上游错误事件。
- Go 聚焦测试、`cmd/server` 编译切片、前端类型检查和 scoped diff check 通过。
